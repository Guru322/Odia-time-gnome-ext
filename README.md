
# Odia Time GNOME Extension

A GNOME Shell extension that replaces the default clock with Odia-formatted time and date while maintaining full calendar functionality.

![Odia Time Extension](https://cdn.jsdelivr.net/gh/Guru322/Odia-time-gnome-ext@refs/heads/Guru/odia-time.png)

## Features
- Displays time and date in **Odia**.
- **Replaces the default clock** in the top panel.
- **Opens the GNOME calendar** on click, properly aligned.
- **Smooth and readable formatting** for better visibility.

## Installation

1. **Clone the repository**:
   ```sh
   git clone https://github.com/Guru322/Odia-time-gnome-ext.git ~/.local/share/gnome-shell/extensions/odia-time@gurucharan.me
   ```
   
2. **Enable the extension**:
   ```sh
   gnome-extensions enable odia-time@gurucharan.me
   ```

3. **Restart GNOME Shell**:
   - Press `Alt + F2`, type `r`, and press `Enter`.
   - Alternatively, log out and log back in.

## Compatibility
- Tested on **GNOME 42.9**.
- May need minor tweaks for other versions.

## Notes
- Clicking the clock will **toggle the GNOME calendar**.
- Time and date are shown in a **single line for better readability**.
- The extension ensures the **calendar opens in the correct position** below the top panel.
